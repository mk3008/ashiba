# Brownfield adoption

The AF-V and AF-L controls are the benchmark's brownfield approximation. They
freeze a pre-existing vertical-slice or layered application shape, pg pool,
transaction seam, DTO ownership, and tests. Candidates add only the specified
data-access behavior; a treatment-driven application-wide rewrite is outside
the control.

This is evidence about local integration into these two small skeletons. It
does not establish migration cost for an arbitrary production application,
team conventions, existing schema ownership, or operational deployment.
Architecture observations remain separate from the primary live matrix.
