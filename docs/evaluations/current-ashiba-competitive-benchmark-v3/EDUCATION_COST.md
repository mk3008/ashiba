# Education and context cost

## Measure

Education cost is the product-specific material a user or agent must
understand: package guidance, concepts, commands, configuration, schema or
contract conventions, generated-state lifecycle, repair instructions, and
documentation lookups. It is not token cost.

## Frozen treatment boundary

Ashiba received the packed `@ashiba-ts/named-parameters` package and current
minimal consumer guidance. It did not receive a CLI, generator, static binding
artifact, source hash, freshness workflow, repository framework, or historic
Ashiba examples. Major arms received only their own frozen official packet;
the benchmark author did not supply a bespoke tutorial to any arm.

## Evidence and limitation

Prompts, packet hashes, candidate source, command logs, and repairs are
preserved per attempt. Token and credit telemetry are unavailable. The present
extractor does not normalize words read, implicit model knowledge, or
candidate reasoning effort into a cross-arm score. Therefore this study can
describe supplied surfaces, but cannot claim a precise education-cost ranking.
