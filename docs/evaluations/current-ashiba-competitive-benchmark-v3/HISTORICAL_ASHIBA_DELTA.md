# Historical Ashiba to Current Ashiba delta

Historical evaluations record a broader Ashiba surface that included CLI and
generated-state workflows. Current Ashiba is intentionally narrower: it has
no public CLI, generator, committed binding artifact, source-hash/freshness
lifecycle, driver adapter ownership, scaffold, contract CLI, or SQL-resource
snapshot.

**Observed current-treatment boundary.** Arm A uses only a packed
named-parameter package, visible SQL, direct compile/bind calls, and native
pg. This is a real difference from historical product workflows.

**Not comparable without further evidence.** Historical benchmark outcomes
must not be reused as Current Ashiba outcomes. This benchmark does not yet
measure a before/after causal effect of surface reduction on defect rates,
repairs, education cost, architecture coupling, generated churn, or detection
latency. The present documents use history for scope context only.
