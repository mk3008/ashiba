# Model familiarity and discoverability

## What was controlled

Primary cells used a shared Fresh-Agent profile, permissions, shell, network
policy, timebox, and runner-facing API. Each arm could use only its frozen
own-product documentation/guidance packet and installed dependencies. A
candidate could not inspect another arm, another replicate, previous output,
or the benchmark archive.

## What was not measured

Model pretraining exposure is an unobserved confounder. This study does not
measure training data, memorization, or inherent model knowledge. It must not
describe a first-pass result as proof that a product is easier to learn.

## Observations retained

The durable attempts preserve package locks, prompts, arm packets, command
logs, candidate source, first-pass command slots, repair attempts, and runner
outcomes. These support later inspection of documented lookups and API errors
when the source records them. Token and credit telemetry are unavailable and
are not estimated.

## Interpretation

Ashiba was supplied as a packed public package with short current guidance;
the established tools received their frozen official product material. That
is an AI-era adoption condition, not an attempt to equalize assumed
pretraining familiarity. Any cross-arm interpretation must remain limited to
the exact model/profile and packets frozen here.
