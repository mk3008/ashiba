# Frozen layered baseline

This is a runner-owned ordinary TypeScript layered application boundary. The
candidate receives a copy of the source tree but not the trusted hash manifest.
It may implement the G1 feature inside the supplied presentation, application
and data-access layers.

Pool, transaction, DTO and test seams belong to the application. The baseline
does not prescribe a repository/unit-of-work framework or a schema DSL.

## sqlc generated query path

The main data-access path imports `src/data-access/generated/queries_sql.ts`,
generated by sqlc 1.31.1 with the official `sqlc-gen-typescript` 0.1.3 WASM
plugin configured in `sqlc.yaml`. The checked-in query source is
`sqlc/queries.sql`; it contains only application queries, not DDL.

The runner owns the DDL template. For regeneration, materialize its
`packet/schema.sql` to the ignored `sqlc/schema-for-generation.sql` after
replacing `{{schema}}` with `public`, then run:

```powershell
sqlc generate
```

Generated file: `src/data-access/generated/queries_sql.ts`.
