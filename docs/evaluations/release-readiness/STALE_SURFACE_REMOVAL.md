# Stale current-surface removal

The release navigation no longer presents historical scaffold, driver-adapter,
safe-sort runtime, optional-condition compression, migration generation,
`applyPlan`, `pg_dump` wrapper, performance tooling, or removed query-analysis
commands as current Ashiba capabilities.

The normative Scope was aligned to the Builder Mapper boundary: Ashiba owns
visible canonical SQL preparation and deterministic binding; applications or
external tools own pools, transactions, logging, mapping, migrations, schema
pull, deployment, and architecture choice. Historical evaluation records were
preserved rather than rewritten.
