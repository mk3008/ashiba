# Maintenance Surface

Keeping the family means owning four public package contracts, generated query-model compatibility, driver-version matrices, peer dependency semantics, build/type/test scripts, documentation, observer/error taxonomy, live PG coverage, adapter-specific fixtures, and migration obligations. It also asks users to choose optional wrappers in addition to native drivers.

Removing or reducing packages does not remove named lowering, driver support, PostgreSQL contract verification, or application tests. It does move thin glue to applications and requires a migration note for Support Inbox/current published APIs. That one-time migration cost is distinct from permanent wrapper ownership.

The narrow residual question is metadata transformation. Optional compression's fail-closed coordinate validation is a real deterministic proof. Safe sort's current package placement is not independently justified by the prior ablation. A future implementation must preserve any retained guard without retaining application execution, logging, retry, or feature-architecture APIs by accident.
