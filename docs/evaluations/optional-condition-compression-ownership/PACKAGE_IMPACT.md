# Driver-Adapter Package Impact

## `@ashiba-ts/driver-adapter-pg`

Removing compression means no remaining capability from this evaluation
requires the pg package. Ordinary preparation, runtime source-hash, safe sort,
and contract profile were already reduced or delegated by the PostgreSQL
Preparation Residual Ownership Evaluation. This decision therefore removes the
last pending reason to preserve the package as an Ashiba product surface.

## `@ashiba-ts/driver-adapter-core`

Compression metadata types are a current residual in core. Removing the
capability allows their extraction or deletion by actual consumer, strengthening
the existing core REMOVE-candidate decision. This evaluation does not decide
the exact type file or migration order.

## What remains unchanged

* `@ashiba-ts/named-parameters` retains binding/lowering ownership.
* `model-gen` retains independent binding and result/analysis responsibilities.
* PostgreSQL contract remains a separate optional capability.
* Native PostgreSQL execution remains application-owned.
* MySQL/mysql2 and SQL Server/mssql support positions do not change.
