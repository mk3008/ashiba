# Responsibility inventory and classification basis

This is an inventory of existing surfaces, not a promotion of their names into rules. “Evidence” identifies the currently observed responsibility; the final classification records the proposed placement for this phase. The preregistered G1 treatment used a broader bounded-syntax candidate rule; the post-run proposal narrows that rule to the ordering capability actually exercised by W2.

| README and Runtime Boundary | Describes canonical `.sql`, development-time CLI, thin adapter scope, and application-owned transaction/workflow policy. | Repository `README.md`; [`runtime-boundary.md`](../../../guide/runtime-boundary.md) | Normative Rule source for canonical ownership and application boundary; explanatory guide otherwise. |
