Change the default feature scaffold to a SQL-first verification layout centered on `query.sql`, `feature.ts`, generated metadata, and DB-backed query tests.

The old RFBA-style `input.ts`, `workflow.ts`, and `output.ts` file split is no longer generated by default. Those files remain valid as application-owned or legacy verbose structure, but the default review target is now visible SQL, DB impact, contract drift, generated support artifacts, and DB-backed test evidence.
