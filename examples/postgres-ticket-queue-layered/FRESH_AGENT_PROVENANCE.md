# Fresh-agent provenance

This reference originated in the clean-room trial recorded in
`docs/evaluations/release-readiness/`. The trial used packed CLI and binding
tarballs, frozen DDL, a short consumer prompt, and no Ashiba source/examples as
inputs. This repository copy uses `workspace:*` only so repository CI tests the
current packages; that is not the clean-room distribution proof.

`ORIGINAL_PROMPT.md` is the concise consumer input. The separately named
`FRESH_AGENT_HARNESS_PROMPT.txt` is evaluation-only isolation evidence. The
layered application itself was not regenerated during the VSA evidence
correction.
