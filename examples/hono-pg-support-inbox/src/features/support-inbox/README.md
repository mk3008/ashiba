# Historical Support Inbox dogfood

This directory is retained as historical dogfooding and integration evidence.
It is not a current feature-scaffold recipe or a required Ashiba architecture.

For a current application starting point, use the minimal, vertical-slice, or
layered ticket queue references. Current Ashiba guidance is limited to visible
canonical SQL, generated binding metadata/freshness, `bindNamedParameters`, and
application-owned native-driver execution. Pools, transactions, logging,
mapping, migrations, and feature layout belong to the application.
