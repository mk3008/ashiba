# V3 amendment

Rules v3 changes Rule 5 only. It removes evaluation-specific wording and makes
the contract permanent: use application-facing native named parameters when a
selected driver supports them; preserve meaningful names in source; and treat
deterministic positional lowering as an application-owned adapter concern, not
a reason to adopt a framework. PostgreSQL remains unimplemented and out of the
V3 live lane.

V0, V1, V2, and the previous amendment record were not edited.
