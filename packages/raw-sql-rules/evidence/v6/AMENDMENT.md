# V6 amendment

V6 promotes the V5 two-state verification result into Rule 8. The unchanged
runtime-authority principle now has a normal case (follow existing
database-backed regression evidence) and a narrow bootstrap exception (create
one smallest reusable authority path when none exists). It does not add a
framework, helper, completion-contract layer, testkit, or mechanical gate.

V0 through V5 evidence remains unchanged.
